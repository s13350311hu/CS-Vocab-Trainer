# Data & Third-party Notice

## 1. Vocabulary data

The project combines original project data with third-party vocabulary sources. Before making a public repository or redistributing the full dataset, verify the original license/terms for every included word list.

The MIT License in this repository applies to the project's original code only. It does not by itself license third-party vocabulary datasets.

## 2. Dictionary lookup

The application may query a public dictionary service for additional pronunciation, definitions, and examples. Any use of that service should follow its current terms, rate limits, and attribution requirements.

## 3. Browser speech

Pronunciation playback can use the browser's built-in Web Speech API. The available voices are supplied by the user's browser/operating system.

## 4. Personal learning data

Learning records are intended to be stored locally in the browser. Do not put private personal information or credentials into this repository.
